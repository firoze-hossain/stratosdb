Quick Start

Multi-Arch Docker (amd64 / arm64)

docker run -d --name stratosdb \
  -p 5432:5432 -p 3306:3306 -p 5431:5431 \
  stratosdb:2.0.0

See Docker Deployment Guide.

Kubernetes 3-Node Raft HA + TLS

helm install stratosdb ./deploy/helm/stratosdb \
  --set raft.enabled=true \
  --set raft.clusterSize=3 \
  --set tls.enabled=true

Brings up a 3-node TLS-secured Raft cluster in < 60s. See Helm README.

Pure-Java Type 4 JDBC Driver

String url = "jdbc:stratos://localhost:5431/stratos";
Connection c = DriverManager.getConnection(url, "admin", "admin");

Maven artifact: com.stratosdb:stratosdb-jdbc:1.0.0-SNAPSHOT. See Client Connectivity.
